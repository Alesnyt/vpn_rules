### Обновления

Адреса файлов постоянные. Повторный импорт свежей строки обновляет профиль с тем же именем. Happ не начинает самостоятельно опрашивать GitHub после импорта такой строки.

Для получения правил кнопкой «Обновить подписку» их нужно включить в ответ существующего сервера подписок. Эта интеграция пока **не подключена**. Изменение `vpn_rules.conf` само по себе не пересобирает Happ-файлы: их обновляют генератором после проверки.
